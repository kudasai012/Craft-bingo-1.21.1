# CraftBingo

**Бинго в Minecraft — выбивай предметы, закрывай клетки, соревнуйся с друзьями!**

Мод добавляет в Minecraft полноценный режим **Bingo**. Каждый игрок получает карточку со случайными предметами. Добудь предмет — клетка закрашивается. Кто первый закроет ряд, столбец или диагональ — тот победил!

## 🎮 Режимы игры

| Режим         | Описание                                | Победа                                            |
|---------------|-----------------------------------------|---------------------------------------------------|
| **Classic**   | Классическое бинго на поле 4×4          | Собрать 4 в ряд (горизонталь/вертикаль/диагональ) |
| **Sprint**    | 3 предмета на выбор, кто первый соберёт | Собрать **любой 1** предмет из 3                  |
| **Fullboard** | Собрать все предметы на поле            | Собрать **все** предметы                          |

---

## 🏆 Сложность

| Сложность   | Описание                                   |
|-------------|--------------------------------------------|
| **Лёгкий**  | Дерево, камень, базовый крафт — 1–3 минуты |
| **Средний** | Железо, редстоун, утилиты — 3–10 минут     |
| **Сложный** | Алмазы, Незер, Энд, редкое — 10–30+ минут  |

## 📋 Команды

| Команда                                     | Действие                                      |
|---------------------------------------------|-----------------------------------------------|
| `/bingo start`                              | Запустить игру с текущими настройками         |
| `/bingo start classic [easy/medium/hard]`   | Классический режим                            |
| `/bingo start sprint [easy/medium/hard]`    | Спринт-режим                                  |
| `/bingo start fullboard [easy/medium/hard]` | Полное поле                                   |
| `/bingo stop`                               | Остановить игру                               |
| `/bingo settings`                           | Открыть настройки (сетка, сложность, режим)   |
| `/bingo status`                             | Показать статус игры                          |
| `/spec`                                     | Войти/выйти из режима наблюдения              |
| `/spec <игрок>`                             | Наблюдать за конкретным игроком               |
| `/spec next`                                | Следующий игрок                               |
| `/spec prev`                                | Предыдущий игрок                              |
| `/spec leave`                               | Выйти из наблюдения                           |

## ✨ Возможности

- 🎲 Случайная карточка для каждого игрока
- ✅ Автоматическая проверка предметов в инвентаре (включая сетку крафта!)
- 🏆 Объявление победителя в чат с фейерверками
- 📊 Прогресс-бар в TAB
- ⏱️ Таймер в BossBar
- 👁️ Режим наблюдения за другими игроками
- 🔄 Сохранение позиции при возврате из бинго-мира
- 💀 Координаты смерти с кликабельным `/tp`
- 🎯 Отдельный мир для каждой игры (Fantasy API)
- 📦 Возврат в основной мир после игры

---

## 🎯 Как играть

1. Выполните `/bingo start` — начать игру  
2. Смотрите на карточку (она отображается в интерфейсе)  
3. Добывайте предметы из списка  
4. Когда соберёте предмет — клетка закрашивается  
5. Соберите ряд / диагональ / всё поле — **победа!**

## 📥 Установка

1. Установите **Fabric Loader** для Minecraft 1.21.1  
2. Скачайте **Fabric API** и поместите в папку `mods`  
3. Скачайте **Fantasy** и поместите в папку `mods`  
4. Скачайте **CraftBingo.jar** и поместите в папку `mods`
